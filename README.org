* JanOS

JanOS is a freestanding 32-bit x86 operating system. GRUB loads the kernel
through Multiboot2 and supplies the initial user application as a boot module.

The kernel currently includes higher-half paging, physical and virtual memory
management, slab allocation, SMP discovery and startup, interrupts, PS/2 input,
serial/VGA output, PCI, AHCI/ATA storage, FAT16, processes, static ELF loading,
and a small syscall ABI. The bundled calculator runs in ring 3.

** Build

Build the cross-toolchain once:

#+begin_src sh
cd tools
./get_tools.sh
#+end_src

Configure and build JanOS with Meson and Ninja:

#+begin_src sh
meson setup build --cross-file config/i686-elf.ini \
  --prefix=/usr --libdir=lib32
meson compile -C build
meson test -C build --print-errorlogs
meson compile -C build iso
#+end_src

Run or debug the generated image:

#+begin_src sh
meson compile -C build run
meson compile -C build debug
#+end_src

The debug target starts QEMU paused with a GDB server on port 1234. Optional
disk paths are configured with ~qemu_disk~, ~qemu_sata_disk1~, and
~qemu_sata_disk2~.

Install the kernel and user SDK into a staging sysroot:

#+begin_src sh
DESTDIR="$PWD/dist/sysroot" meson install -C build
#+end_src

See ~docs/structure.md~ for subsystem ownership, ~docs/applications.md~ for
building client applications with the JanOS C library, and ~docs/testing.md~
for the staged host and QEMU test strategy.
